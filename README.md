# 📱 Duolingo — Practice

Projeto desenvolvido em **Android Studio** como parte da avaliação **“Clonando o Layout de um App Famoso”**.

A proposta foi recriar uma tela inspirada na interface do **Duolingo**, utilizando **XML e ConstraintLayout**, trabalhando com organização dos elementos, cores, tipografia, espaçamentos e componentes de interface.

## 🎯 Objetivo

Criar uma interface semelhante à tela de prática do aplicativo escolhido, aplicando os conceitos de desenvolvimento de interfaces Android.

## 🛠️ Tecnologias

- Kotlin
- XML
- Android Studio
- ConstraintLayout
- AndroidX
- Material Components
- Gradle

## 📱 Interface

A tela possui:

- Título da seção de prática
- Indicador de vidas
- Cards de atividades
- Ícones e descrições
- Botões de navegação
- Mascote
- Mensagem informativa
- Botão de ação
